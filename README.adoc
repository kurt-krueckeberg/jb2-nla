= Lower Saxony, Bückeburg Archive, Documents (Jupyter Book 2)

Jupyter Book 2 (MyST) version of the
https://github.com/kurt-krueckeberg/sphinx-nla[sphinx-nla] Jupyter Book 1 project:
transliterations and translations of Schaumburg-Lippe Rentkammer case files
from the Bückeburg branch of the Lower Saxony state archive.

All configuration, including the table of contents and the PDF export, is in `myst.yml`.

== Requirements

* Jupyter Book 2: `pip install -r requirements.txt`
* Node.js 18 or later
* Typst, for the PDF

== Build

[source,bash]
----
jupyter book start          # serve the site as a MyST application (http://localhost:3000)
jupyter book build --html   # static HTML in _build/html
jupyter book build --pdf    # Typst PDF in exports/book.pdf
----
